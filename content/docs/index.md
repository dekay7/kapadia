# Introduction

> [!TIP]
> **New to kapadia.org?** Start with the [Getting Started](#getting-started) guide to learn how to use our technical utilities and research notes.

Welcome to the technical heart of kapadia.org. This documentation hub contains everything you need to understand, use, and self-host the utilities found on this site.

## Explore the Docs

- **[Getting Started](#getting-started)**: A beginner's guide to navigating the site.
- **[Speed Test](#tool-speed)**: Detailed explanation of how the network diagnostic tool works.
- **[Link Inspector](#tool-link)**: Trace redirect chains, score URL safety, and surface domain intelligence — before you click.
- **[OSINT Footprint](#tool-osint)**: Open-source intelligence checks across IPs, domains, usernames, and email — including full email authentication analysis (DKIM, DMARC, MTA-STS, BIMI).
- **[EXIF Inspector](#tool-exif)**: Browser-native metadata extraction and stripping for photos. No upload required.
- **[DNS Analyzer](#tool-dns)**: DNS record lookups via a secure DNS-over-HTTPS resolver.
- **[Browser Fingerprint](#tool-leak)**: What your browser exposes — headers, TLS data, and browser API values.
- **[Hash Generator](#tool-hash)**: In-browser cryptographic hashing using Web Crypto API and SparkMD5.
- **[JWT Decoder](#tool-jwt)**: Split and decode JSON Web Tokens entirely client-side.
- **[Payload Encoder](#tool-encode)**: Base64, URL, Hex, and HTML encoding/decoding with no server involvement.
- **[Subnet Calculator](#tool-subnet)**: CIDR subnet math — fully client-side.
- **[Supply Chain Auditor](#tool-chain)**: Audit third-party scripts on any page — verify SRI hashes, detect CDN tampering, and cross-reference npm registry integrity.
- **[API Reference](#api-reference)**: How to programmatically access visitor data, OSINT, and link-inspection endpoints.
- **[Self-Hosting Curl IP](#curl-ip-selfhost)**: Instructions for running your own IP detection service.
