EXIF Inspector

Strip hidden photo metadata — GPS coordinates, device info, and timestamps. Runs entirely in your browser — nothing is uploaded.

Privacy: Files are read locally by your browser's FileReader API — nothing is uploaded to any server. EXIF parsing uses the exifr library, self-hosted on this domain (no CDN). Clicking a GPS coordinate link opens OpenStreetMap in a new tab — OpenStreetMap only receives your IP if you click the link.
