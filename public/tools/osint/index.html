OSINT Footprint Checker

Investigate IPs, domains, usernames, and email addresses using open-source intelligence. All lookups route through the edge — no data is stored.

Privacy: Lookups run via a Cloudflare edge function — your IP is not exposed to third-party services; they see the edge IP. Sources used per mode: IP — ipwho.is, Cloudflare DoH; Domain — RDAP (rdap.org), Cloudflare DoH, crt.sh; Username — GitHub, GitLab, Hacker News, Docker Hub, npm (may include publicly-set email); Email — Cloudflare DoH. No queries or results are logged or stored. See documentation for full details.
