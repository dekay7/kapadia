Supply Chain Auditor

Audit every third-party script and stylesheet on a page — verify SRI hashes, detect CDN tampering, and cross-reference published npm package integrity. All fetching runs at the edge.

Privacy: The target page and its third-party resources are fetched server-side by a Cloudflare edge function — your browser never contacts them. Third-party services used server-side: Cloudflare DNS-over-HTTPS (cloudflare-dns.com) for SSRF prevention; npm registry (registry.npmjs.org) and cdnjs API (api.cdnjs.com) for package integrity cross-reference. No URLs or results are logged or stored by kapadia.org.
