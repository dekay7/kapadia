kapadia.org · tools

Security & Networking

Lightweight, edge-native utilities for security, diagnostics, and operational privacy.

~/speed

Speed Test

Measure network throughput and latency.

 ~/link

Link Inspector

Trace redirects and surface safety signals before you click. Self-hosted.

 ~/email

Email Analyzer

Check if an email is genuine and spot spoofing. No data sent.

 ~/osint

OSINT Footprint

Look up IPs, domains, usernames, and emails across public sources. Self-hosted.

 ~/exif

EXIF Inspector

Extract and strip photo metadata from images. No data sent.

 ~/leak

Browser Fingerprint

See what headers, TLS ciphers, and signals your browser is leaking. Self-hosted.

 ~/hash

Hash Generator

Hash text with MD5, SHA-1, SHA-256, or SHA-512. No data sent.

 ~/dns

DNS Analyzer

Query DNS records over HTTPS — A, AAAA, MX, TXT, CNAME. Self-hosted.

 ~/jwt

JWT Decoder

Decode and inspect JWTs. No data sent.

 ~/encode

Payload Encoder

Encode and decode Base64, URL, and Hex strings. No data sent.

 ~/subnet

Subnet Calculator

Calculate network boundaries and host ranges from any IP/CIDR. No data sent.

 ~/chain

Supply Chain Auditor

Audit third-party scripts on any page for SRI integrity and supply chain risk. Self-hosted.
