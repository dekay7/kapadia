kapadia.org · tools

Security & Networking

Lightweight, edge-native utilities for security, diagnostics, and operational privacy.

~/speed

Speed Test

Edge-native network throughput and latency diagnostics. Optimized for performance and privacy.

 ~/link

Link Inspector

Trace redirect chains, score link safety, and surface domain and security signals before you click.

 ~/osint

OSINT Footprint

Investigate digital footprints across IP addresses, domains, usernames, and email addresses using public intelligence sources.

 ~/exif

EXIF Inspector

Extract and strip hidden metadata from photos including GPS coords, device models, and timestamps entirely client-side.

 ~/leak

Browser Fingerprint

See exactly what HTTP headers, TLS ciphers, and fingerprinting data your browser is leaking.

 ~/hash

Hash Generator

Calculate MD5, SHA-1, SHA-256, and SHA-512 hashes instantly in your browser using the Web Crypto API.

 ~/dns

DNS Analyzer

Query a secure DNS-over-HTTPS (DoH) resolver to retrieve A, AAAA, MX, TXT, and CNAME records instantly.

 ~/jwt

JWT Decoder

Decode and inspect JSON Web Tokens safely. 100% offline, zero network requests made.

 ~/encode

Payload Encoder

A micro-utility to encode and decode Base64, URL, and Hex strings on the fly.

 ~/subnet

Subnet Calculator

Quickly calculate network boundaries, broadcast addresses, and usable host ranges from any IP/CIDR.
