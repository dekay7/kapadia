Email Analyzer

Check if an email is genuine. Paste headers or full source to spot spoofing and trace the relay chain. No data sent.

Privacy: All header analysis runs 100% in your browser — no header data is sent to any server. Optionally, clicking Run OSINT Analysis sends the originating IP and sender domain to the site's OSINT API for server-side enrichment; no email body or personal data is included.
How to get email headers or source

Paste the full email source or just the headers — the tool only needs the headers and will ignore the body automatically.

  • Gmail — open email → ⋮ → Show original → Copy to clipboard
  • Outlook (web) — open email → ⋮ → View → View message source → Ctrl+A, Ctrl+C
  • Outlook (desktop) — File → Properties → Internet headers box → Ctrl+A, Ctrl+C
  • Apple Mail — View → Message → Raw Source → ⌘A, ⌘C
  • Thunderbird — Ctrl+U to open message source → Ctrl+A, Ctrl+C
