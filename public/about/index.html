kapadia.org is where I publish the security tools, research notes, and technical writing that grow out of my work in detection engineering, identity security, and cloud platforms. The site includes browser-based diagnostics, documentation, essays, and a terminal interface for people who prefer the command line.

It runs on Cloudflare's edge network and keeps the mechanics plain with semantic HTML, CSS, and small JavaScript files. There are no cookies, trackers, or advertising. Some tools work entirely in your browser; the ones that need network data use carefully scoped edge functions. You can browse normally or run curl kapadia.org to see the site's terminal-facing side.

I use AI assistance while building it, but each change is reviewed, tested, and kept understandable. That discipline has made this a practical place to try ideas, document what I learn, and share tools that respect the people using them.

The diagnostic tools, technical documentation, and writing are here to be used and picked apart.

I also curate a terminal-based job board for Cybersecurity and IT roles at itseclist.com. Browse the latest postings straight from your shell with ssh itseclist.com.
